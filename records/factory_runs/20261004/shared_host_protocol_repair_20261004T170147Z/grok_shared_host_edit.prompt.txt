# Shared host import prototype: not admitted

The pinned draft (`21a0379e778bdb8c31e5da7774410b59236e2b6f72a87eaf1b68ff584a666815`) remains source only. ROOT read the source and current Khronos specification. No compile, memory import or GPU submission is admitted by this review.

Three issues prevent using this draft as evidence of a valid transport:

1. The producer releases one buffer view while the consumer acquires a different view of the same host payload in another instance. The specification permits repeated host-payload imports and defines FOREIGN ownership, but also says ownership transfer leaves other aliased resources' contents undefined. This review does not establish that the draft's two views qualify as the corresponding external resource. That question remains unresolved; byte parity alone would not resolve it.
2. The negative control writes the original host pointer after the producer's release and before the consumer's acquire. The ownership rules prohibit an acquire after intervening modification other than a matching release. A revised control should corrupt on the producing GPU before its release, or use a separately justified host-domain protocol. The same original pointer is not inherently forbidden for HOST_VISIBLE imports; access still needs a correct synchronization protocol.
3. The private readback budget is checked after both allocations. Each allocation must be checked against a per-device share of the budget before `vkAllocateMemory`. Capability and alignment failures must remain refusals.

The contract also overstates undefined contents on import: that restriction is described for imports into non-host-visible memory. This draft explicitly requires HOST_VISIBLE and HOST_COHERENT types. General memory-import text requires preserving the imported contents. The source initializes host RAM before import, despite the contract saying it does not; that initialization cannot be described as GPU-produced data.

- [Host pointer import](https://docs.vulkan.org/refpages/latest/refpages/source/VkImportMemoryHostPointerInfoEXT.html): same payload may be imported into multiple instances; original-pointer access and lifetime restrictions.
- [Memory allocation](https://docs.vulkan.org/spec/latest/chapters/memory.html): import contents, host visibility and host cache synchronization.
- [Synchronization](https://docs.vulkan.org/spec/latest/chapters/synchronization.html): external ownership, matching ranges, intervening modification and alias contents.

The selected Vulkan instances are intentionally separate, one per physical device. The source uses `VK_QUEUE_FAMILY_FOREIGN_EXT` for cross-instance handoff. It must never substitute `VK_QUEUE_FAMILY_EXTERNAL`: the latter is limited to the same physical device and driver, while `FOREIGN` is defined for resources accessed outside the current Vulkan instance and supports different devices/drivers when the extension is advertised and enabled.

## Payload and rounds

The payload is exactly 262,144 bytes, divided into 64 aligned 4,096-byte chunks. GPU producer work consists of 64 `vkCmdFillBuffer` commands, one per chunk, with deterministic but distinct 32-bit values derived from a fixed seed. The CPU constructs a separate expected byte vector before submission; it never initializes the shared payload. For each direction, the other GPU acquires the imported shared buffer and issues one `vkCmdCopyBuffer` into its own private readback buffer. After the consumer's fence signals, compare every payload byte against the producer's expected vector.

Run sequentially:

1. NVIDIA produces and AMD consumes; require 262,144/262,144 bytes equal.
2. AMD produces and NVIDIA consumes; require 262,144/262,144 bytes equal.
3. NVIDIA produces a fresh pattern and releases it; after that producer fence has signaled and before the AMD acquire, the CPU flips byte offset 12,345 in the shared `VirtualAlloc` payload. AMD consumes and the CPU compares all bytes to the uncorrupted expected vector. The negative control passes only if the full scan detects exactly one mismatch, at offset 12,345, with the returned byte equal to expected XOR `0x01`.

No CPU payload copy is allowed between producer and consumer. The CPU may read the consumer's private readback for full verification and may mutate the one declared corruption byte only in round 3.

## Ownership and synchronization protocol

All imports/resources are created before the first GPU use. A newly created exclusive buffer has no owner until its first queue use; the first NVIDIA producer use is therefore the Vulkan-defined implicit first-use acquire on its local queue. Every subsequent use explicitly follows the external-ownership cycle below. For each imported buffer alias and exact `[0, 262144)` range:

1. Producer records its writes, then a release `VkBufferMemoryBarrier` from its local transfer queue family to `VK_QUEUE_FAMILY_FOREIGN_EXT` (`TRANSFER_WRITE` to no destination access). Submit with a fence and wait at most 5 seconds.
2. The CPU proceeds only after that producer fence signals. This is host-side control; no inter-device payload staging occurs.
3. Consumer records a matching acquire barrier from `VK_QUEUE_FAMILY_FOREIGN_EXT` to its local transfer queue family (no source access to `TRANSFER_READ`), copies shared buffer to its private readback, adds a transfer-write-to-host-read barrier for the readback, and releases the shared range back to `FOREIGN_EXT` after the read.
4. Submit with a consumer fence and wait at most 5 seconds. Only after it signals may the CPU inspect readback, alter the declared corruption byte, or begin the next round.

The implementation must preserve Vulkan's exact matching release/acquire range and queue-family indices. It must not use `VK_QUEUE_FAMILY_EXTERNAL` for this cross-vendor path. In each context, later producer use reacquires its buffer from `FOREIGN_EXT`; consumer use also acquires from `FOREIGN_EXT`. The source draft explicitly relies on the external-memory ownership model applying to the corresponding buffer views independently bound to the same imported host payload. Root must review this alias/handoff assumption against the spec and driver model before any compile or run. If that correspondence cannot be justified, the fixture stops here rather than weakening ownership synchronization.

Each individual `vkWaitForFences` timeout is 5 seconds. There is no infinite fence, queue-idle, or device-idle wait. A timeout or error after successful queue submission must terminate the child without running destructors that could free the host pointer while device work might remain active; process teardown is the cleanup boundary. Normal teardown occurs only after all submitted fences have signaled: unmap and destroy private readback buffers/memory, destroy each shared buffer before its imported `VkDeviceMemory`, destroy each device/instance, then `VirtualFree` the shared allocation. An outer retained-process supervisor must enforce 30 seconds total, capture bounded stdout/stderr, and verify child reaping before this prototype is ever run.

## Evidence fields and interpretation

The eventual runtime record should report selected vendor/device IDs and UUIDs, driver UUIDs, extension presence/enabled state, queried and pointer-specific handle/feature/type masks, minimum and actual pointer/resource alignment, per-device memory requirements and selected heap/type flags, allocation-request totals, all three byte counts/mismatch offsets, each fence outcome, and overall elapsed time. Transport text remains `SHARED_HOST_BACKING_NOT_VRAM_P2P`; there is no P2P or VRAM claim even on byte parity. Unsupported gates must be `NOT_CHECKED`/`REFUSED`, not coerced into a failure or success.

void submitAndWait(Context& c, const std::function<void(VkCommandBuffer)>& record,
                   const char* label) {
    VkCommandBufferAllocateInfo cai{VK_STRUCTURE_TYPE_COMMAND_BUFFER_ALLOCATE_INFO};
    cai.commandPool = c.commandPool;
    cai.level = VK_COMMAND_BUFFER_LEVEL_PRIMARY;
    cai.commandBufferCount = 1;
    VkCommandBuffer cmd = VK_NULL_HANDLE;
    check(vkAllocateCommandBuffers(c.device, &cai, &cmd), "vkAllocateCommandBuffers");
    VkCommandBufferBeginInfo begin{VK_STRUCTURE_TYPE_COMMAND_BUFFER_BEGIN_INFO};
    begin.flags = VK_COMMAND_BUFFER_USAGE_ONE_TIME_SUBMIT_BIT;
    check(vkBeginCommandBuffer(cmd, &begin), "vkBeginCommandBuffer");
    record(cmd);
    check(vkEndCommandBuffer(cmd), "vkEndCommandBuffer");

    VkFenceCreateInfo fci{VK_STRUCTURE_TYPE_FENCE_CREATE_INFO};
    VkFence fence = VK_NULL_HANDLE;
    check(vkCreateFence(c.device, &fci, nullptr, &fence), "vkCreateFence");
    VkSubmitInfo submit{VK_STRUCTURE_TYPE_SUBMIT_INFO};
    submit.commandBufferCount = 1;
    submit.pCommandBuffers = &cmd;
    const VkResult queued = vkQueueSubmit(c.queue, 1, &submit, fence);
    if (queued != VK_SUCCESS) terminateWithPendingWork("vkQueueSubmit failed; process teardown required");
    const VkResult waited = vkWaitForFences(c.device, 1, &fence, VK_TRUE, kFenceTimeoutNs);
    if (waited != VK_SUCCESS) terminateWithPendingWork("5-second CPU fence wait failed or timed out");
    vkDestroyFence(c.device, fence, nullptr);
    vkFreeCommandBuffers(c.device, c.commandPool, 1, &cmd);
    (void)label;
}

    bool pass = false;
};

RoundResult runRound(Context& producer, Context& consumer, void* sharedHostPointer, uint8_t seed,
                     bool injectSingleByteCorruption, const char* name) {
    std::vector<uint8_t> expected = expectedPattern(seed);
    submitAndWait(producer, [&](VkCommandBuffer cmd) {
        if (producer.inForeignOwnership) {
            bufferBarrier(producer, cmd, producer.sharedBuffer, VK_QUEUE_FAMILY_FOREIGN_EXT,
                          producer.queueFamily, 0, VK_ACCESS_TRANSFER_WRITE_BIT,
                          VK_PIPELINE_STAGE_TOP_OF_PIPE_BIT, VK_PIPELINE_STAGE_TRANSFER_BIT);
            producer.inForeignOwnership = false;
        }
        for (uint32_t chunk = 0; chunk < kChunkCount; ++chunk) {
            const uint8_t byte = expected[chunk * static_cast<size_t>(kChunkBytes)];
            const uint32_t fill = uint32_t(byte) * 0x01010101u;
            vkCmdFillBuffer(cmd, producer.sharedBuffer,
                            VkDeviceSize(chunk) * kChunkBytes, kChunkBytes, fill);
        }
        bufferBarrier(producer, cmd, producer.sharedBuffer, producer.queueFamily,
                      VK_QUEUE_FAMILY_FOREIGN_EXT, VK_ACCESS_TRANSFER_WRITE_BIT, 0,
                      VK_PIPELINE_STAGE_TRANSFER_BIT, VK_PIPELINE_STAGE_BOTTOM_OF_PIPE_BIT);
    }, "producer");
    producer.hasUsedAlias = true;
    producer.inForeignOwnership = true;

    if (injectSingleByteCorruption) {
        auto* bytes = static_cast<uint8_t*>(sharedHostPointer);
        bytes[12345] ^= 0x01;
    }

    submitAndWait(consumer, [&](VkCommandBuffer cmd) {
        bufferBarrier(consumer, cmd, consumer.sharedBuffer, VK_QUEUE_FAMILY_FOREIGN_EXT,
                      consumer.queueFamily, 0, VK_ACCESS_TRANSFER_READ_BIT,
                      VK_PIPELINE_STAGE_TOP_OF_PIPE_BIT, VK_PIPELINE_STAGE_TRANSFER_BIT);
        VkBufferCopy copy{};
        copy.srcOffset = 0;
        copy.dstOffset = 0;
        copy.size = kPayloadBytes;
        vkCmdCopyBuffer(cmd, consumer.sharedBuffer, consumer.readbackBuffer, 1, &copy);
        bufferBarrier(consumer, cmd, consumer.readbackBuffer, consumer.queueFamily,
                      consumer.queueFamily, VK_ACCESS_TRANSFER_WRITE_BIT, VK_ACCESS_HOST_READ_BIT,
                      VK_PIPELINE_STAGE_TRANSFER_BIT, VK_PIPELINE_STAGE_HOST_BIT);
        bufferBarrier(consumer, cmd, consumer.sharedBuffer, consumer.queueFamily,
                      VK_QUEUE_FAMILY_FOREIGN_EXT, VK_ACCESS_TRANSFER_READ_BIT, 0,
                      VK_PIPELINE_STAGE_TRANSFER_BIT, VK_PIPELINE_STAGE_BOTTOM_OF_PIPE_BIT);
    }, "consumer");
    consumer.hasUsedAlias = true;
    consumer.inForeignOwnership = true;

    RoundResult result;
    result.name = name;
    result.bytesChecked = static_cast<size_t>(kPayloadBytes);
    const auto* actual = static_cast<const uint8_t*>(consumer.readbackMapped);
    for (size_t i = 0; i < expected.size(); ++i) {
        if (actual[i] != expected[i]) {
            if (result.mismatchCount == 0) {
                result.firstMismatch = i;
                result.expectedAtMismatch = expected[i];
                result.actualAtMismatch = actual[i];
            }
            ++result.mismatchCount;
        }
    }
    result.pass = injectSingleByteCorruption
        ? (result.mismatchCount == 1 && result.firstMismatch == 12345 &&
           result.actualAtMismatch == static_cast<uint8_t>(result.expectedAtMismatch ^ 0x01))
        : (result.mismatchCount == 0);
    return result;
}

void printRound(const RoundResult& r) {
    std::cout << "{\"round\":\"" << r.name << "\",\"bytes_checked\":" << r.bytesChecked
              << ",\"mismatch_count\":" << r.mismatchCount << ",\"first_mismatch_offset\":";
    if (r.firstMismatch == SIZE_MAX) std::cout << "null";
    else std::cout << r.firstMismatch;
    std::cout << ",\"expected_byte_hex\":\"" << std::hex << std::setw(2) << std::setfill('0')
              << unsigned(r.expectedAtMismatch) << "\",\"actual_byte_hex\":\""
              << std::setw(2) << unsigned(r.actualAtMismatch) << std::dec
              << "\",\"pass\":" << (r.pass ? "true" : "false") << "}\n";
}

void printDevice(const Context& c) {
    std::cout << "{\"device\":\"" << c.label << "\",\"name\":\"" << c.properties.deviceName
              << "\",\"vendor_id_hex\":\"0x" << std::hex << c.properties.vendorID
              << "\",\"device_id_hex\":\"0x" << c.properties.deviceID
              << "\",\"device_uuid\":\"" << hexBytes(c.id.deviceUUID, VK_UUID_SIZE)
              << "\",\"driver_uuid\":\"" << hexBytes(c.id.driverUUID, VK_UUID_SIZE)
              << "\",\"queue_family\":" << std::dec << c.queueFamily
              << ",\"foreign_extension_enabled\":true,\"host_import_extension_enabled\":true"
              << ",\"external_memory_features_hex\":\"0x" << std::hex << c.externalMemoryFeatures
              << "\",\"compatible_handle_types_hex\":\"0x" << c.compatibleHandleTypes
              << "\",\"min_host_pointer_alignment\":" << std::dec << c.minHostPointerAlignment
              << ",\"buffer_requirement_alignment\":" << c.sharedRequirementAlignment
              << ",\"buffer_requirement_size\":" << c.sharedRequirementBytes
              << ",\"buffer_requirement_type_bits_hex\":\"0x" << std::hex
              << c.bufferRequirementMemoryTypeBits << "\",\"pointer_type_bits_hex\":\"0x"
              << c.pointerMemoryTypeBits << "\",\"selected_type_index\":" << std::dec
              << c.importedMemoryTypeIndex << ",\"selected_type_flags_hex\":\"0x" << std::hex
              << c.importedTypeFlags << "\",\"selected_heap_flags_hex\":\"0x"
              << c.importedHeapFlags << "\"}\n";
}

}  // namespace

int main() {
    try {
        HostBlock host;
        Context nvidia;
        Context amd;
        nvidia.initialize("NVIDIA", 0x10de, host.pointer);
        amd.initialize("AMD", 0x1002, host.pointer);
        if (std::memcmp(nvidia.id.deviceUUID, amd.id.deviceUUID, VK_UUID_SIZE) == 0)
            throw Failure("selected NVIDIA and AMD deviceUUID values are not distinct");
        const VkDeviceSize readbackTotal = nvidia.readbackAllocationBytes + amd.readbackAllocationBytes;
        if (readbackTotal > kReadbackBudget) throw Failure("private readback allocation budget exceeded");
        printDevice(nvidia);
        printDevice(amd);

        RoundResult nvToAmd = runRound(nvidia, amd, host.pointer, 0x19, false, "NVIDIA_TO_AMD");
        printRound(nvToAmd);
        RoundResult amdToNv = runRound(amd, nvidia, host.pointer, 0x53, false, "AMD_TO_NVIDIA");
        printRound(amdToNv);
        RoundResult corrupt = runRound(nvidia, amd, host.pointer, 0x87, true,
                                       "NVIDIA_TO_AMD_CORRUPTION_CONTROL");
        printRound(corrupt);

        const bool pass = nvToAmd.pass && amdToNv.pass && corrupt.pass;
        std::cout << "{\"status\":\"" << (pass ? "PASS" : "FAIL")
                  << "\",\"transport\":\"SHARED_HOST_BACKING_NOT_VRAM_P2P\"
                  << ",\"sync\":\"CPU_FENCE_CONTROL_NO_CPU_PAYLOAD_TRANSFER\"
                  << ",\"payload_bytes\":" << kPayloadBytes
                  << ",\"private_readback_allocation_bytes\":" << readbackTotal
                  << ",\"p2p_claim\":false,\"vram_residency_claim\":false}\n";
        return pass ? 0 : 1;
    } catch (const std::exception& e) {
        std::cerr << "{\"status\":\"NOT_CHECKED\",\"reason\":\"" << e.what()
                  << "\",\"transport\":\"SHARED_HOST_BACKING_NOT_VRAM_P2P\"}\n";
        return 2;
    }
}
